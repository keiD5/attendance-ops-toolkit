# 근태 운영 툴킷

근태 운영 툴킷은 휴가, 연장근무, 교대근무, 승인 흐름을 운영하는 팀을 위한 작은 오픈소스 시작 도구 모음입니다.

이 저장소는 완성된 근태 앱이 아닙니다. 대신 운영자가 실수하기 쉬운 부분을 놓치지 않도록 도와주는 체크리스트, 템플릿, 공개 전 점검 스크립트를 제공합니다.

쉽게 말하면 실제 금고나 직원 명단이 아니라, 매장을 열기 전에 확인하는 점검표와 기록 양식만 담은 도구 상자입니다.

## 왜 만들었나요?

작은 운영팀은 정식 개발 프로세스가 갖춰지기 전에 근태/승인 도구를 먼저 만들 때가 많습니다. 이때 배포 폴더를 잘못 고르거나, 오래된 파일을 올리거나, 권한 기준을 느슨하게 만들면 실제 사용자 데이터와 운영 흐름에 문제가 생길 수 있습니다.

이 툴킷은 그런 실수를 줄이기 위한 기본 점검 기준을 제공합니다.

## 포함된 내용

- `docs/operations-checklist.ko.md`: 운영 전후 점검표 한국어판
- `docs/release-checklist.ko.md`: 배포 체크리스트 한국어판
- `docs/security-model.ko.md`: 권한과 데이터 보호 모델 한국어판
- `templates/attendance-request-template.ko.md`: 근태 요청 템플릿 한국어판
- `templates/incident-report-template.ko.md`: 사고 기록 템플릿 한국어판
- `docs/review-notes.ko.md`: 현재 구성 검수 메모
- `scripts/scan-public-safety.sh`: 공개 전 민감 정보 흔적을 빠르게 찾는 보조 스크립트

영어 원문도 함께 유지합니다.

## 빠른 사용법

공개 저장소로 올리기 전에 안전 스캔을 실행합니다.

```bash
bash scripts/scan-public-safety.sh .
```

점검표를 읽습니다.

```bash
open docs/operations-checklist.ko.md
open docs/release-checklist.ko.md
```

## 누구에게 유용한가요?

- 작은 내부 운영 앱을 관리하는 사람
- 휴가/근태/승인 흐름을 배포하기 전에 점검표가 필요한 사람
- 비전문가도 이해할 수 있는 운영 문서가 필요한 팀
- 공개 저장소에 민감 정보가 섞이지 않았는지 확인하고 싶은 관리자

## 공개하지 않는 것

이 저장소에는 아래 내용을 넣지 않습니다.

- 실제 운영 코드
- 직원 개인정보
- 비밀번호와 토큰
- Firebase 관리자 키
- 운영 서버 주소
- 회사 내부 전용 규칙 원본
- 실제 근태 기록

## 한계

`scan-public-safety.sh`는 흔한 민감 정보 패턴을 찾는 보조 도구입니다. 모든 비밀값을 100% 찾아주는 보안 제품은 아닙니다.

공개 전에는 항상 사람이 한 번 더 확인해야 합니다. 비유하면 금속탐지기가 위험한 물건을 많이 잡아주지만, 최종 문단속은 사람이 해야 하는 것과 같습니다.
