# Operations Checklist

Use this checklist before changing an attendance, leave, or approval workflow.

## Before Release

- Confirm the target environment.
- Confirm the deployment folder.
- Confirm the app entry file.
- Confirm the currently loaded script versions.
- Confirm no old backup folder is being deployed.
- Confirm private documents are not publicly hosted.
- Confirm user roles are checked by role, not by display name.
- Confirm delegated permissions do not unlock owner-only actions.
- Confirm one-person edits cannot overwrite all users.
- Confirm rollback notes exist.

## After Release

- Open the real public URL.
- Confirm the changed file is visible in the deployed output.
- Confirm pages that should be private return a blocked or missing response.
- Confirm critical workflows still load.
- Confirm access logs or security logs are still available.
- Record what changed and when.

## Simple Analogy

Do not just repaint the office wall.

Check the front door, the storage room, the key cabinet, and the camera before calling the work complete.
