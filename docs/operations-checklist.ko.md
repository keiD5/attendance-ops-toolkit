# 운영 점검표

근태, 휴가, 승인 흐름을 바꾸기 전에 사용하는 점검표입니다.

## 배포 전

- 대상 환경이 맞는지 확인합니다.
- 실제 배포 폴더가 맞는지 확인합니다.
- 앱 진입 파일이 무엇인지 확인합니다.
- 현재 화면이 읽는 스크립트 버전을 확인합니다.
- 오래된 백업 폴더가 배포 대상에 섞이지 않았는지 확인합니다.
- 비공개 문서가 공개 호스팅에 올라가지 않았는지 확인합니다.
- 사용자 권한을 이름표가 아니라 역할 값으로 확인하는지 봅니다.
- 위임 권한이 소유자 전용 기능까지 열지 않는지 봅니다.
- 사용자 1명 수정이 전체 사용자 목록 덮어쓰기나 삭제로 이어지지 않는지 봅니다.
- 되돌림 메모가 있는지 확인합니다.

## 배포 후

- 실제 공개 URL을 직접 엽니다.
- 바꾼 파일이 실제 배포 결과에 들어갔는지 확인합니다.
- 비공개여야 하는 페이지가 차단되거나 없는 페이지로 나오는지 확인합니다.
- 중요한 업무 흐름이 여전히 열리는지 확인합니다.
- 접속 로그나 보안 로그를 계속 볼 수 있는지 확인합니다.
- 무엇을 언제 바꿨는지 기록합니다.

## 쉬운 비유

사무실 벽만 새로 칠했다고 공사가 끝난 것이 아닙니다.

문, 창고, 열쇠함, CCTV까지 확인해야 진짜 운영 점검이 끝납니다.
