# Security Policy

## Reporting a Problem

Please open a private security advisory if the issue involves a secret, credential, private company data, or a workflow that could expose personal information.

If private advisories are not available, contact the maintainer privately before posting details publicly.

## What Should Not Be Public

Do not publish:

- API keys
- private keys
- Firebase service account files
- app signing keys
- employee records
- production database exports
- real attendance records
- screenshots that show private user data
- private deployment URLs

## Maintainer Response

For a credible report, the maintainer should:

- acknowledge the report
- remove or rotate exposed secrets
- document the impact
- publish a fix or mitigation
- add a checklist item to prevent recurrence
